# 4-bit Ripple Carry Adder 

This is a Verilog HDL project to design and simulate a **4-bit Ripple Carry Adder** using **Xilinx Vivado 2023.2**. The design includes RTL, gate-level logic, waveform analysis, and testbench validation.

---

## 📌 Features
- Adds two 4-bit binary numbers (`a[3:0]`, `b[3:0]`)
- Outputs 4-bit sum and 1-bit carry-out
- Fully structural Verilog design (no behavioral)
- Verified with testbench and waveform simulation

---

## 🛠️ Tools Used
- **Vivado 2023.2**
- **Verilog HDL**
- Testbench for simulation
- RTL viewer for schematic generation

---

## 📂 Files Included
- `four_bit.v` – Verilog code for 4-bit RCA
- `testbench.v` – Testbench with sample inputs
- `.xpr` – Vivado project file
- `RTL Schematic Diagram.png` – RTL Schematic
- `Testbench.png` – Testbench Code
- `Verilog Code.png` – Ripple Carry Code
- `Timing Diagram.png` – Simulation Waveform
